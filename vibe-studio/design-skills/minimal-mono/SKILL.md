# 미니멀 모노크롬 스킬 (Minimal Mono)

이 스킬은 색을 거의 쓰지 않고 **타이포그래피·여백·정렬**만으로 위계를 만드는 미니멀 웹 디자인을 재현하기 위한 명세다. 결과물은 SvelteKit 앱이며, 토큰은 `src/app.css`의 `:root`에 정의하고 `src/routes/+layout.svelte`에서 import한다.

---

## 0. 적용 규칙 (먼저 읽을 것)

1. **색은 흑·백·회색 3단계만** 쓴다. 강조가 필요하면 굵기·크기·밑줄로 해결한다. 유일한 예외는 포커스 링과 오류 상태.
2. 모든 색·간격·글꼴은 아래 CSS 변수를 통해서만 쓴다. 하드코딩 금지.
3. **그림자·그라디언트·둥근 모서리 금지.** 면 구분은 1px 선과 여백으로만 한다.
4. 여백은 아낌없이 쓴다. 섹션 사이 최소 120px(데스크톱).
5. 이미지가 있다면 흑백(grayscale) 필터를 기본으로 하고, hover 시 컬러로 바뀌게 할 수 있다.
6. 아이콘은 쓰지 않거나 1.5px 선 아이콘만 쓴다. 이모지 금지.

---

## 1. 디자인 DNA (한 줄 요약)

- **갤러리 같은 고요함**: 흰 바탕에 검은 대형 헤드라인, 회색 보조 텍스트.
- **12컬럼 그리드에 엄격히 정렬**: 텍스트 시작선이 페이지 전체에서 일치한다.
- **시그니처 형태**: 번호가 붙은 리스트(01, 02…)와 화면 폭을 가로지르는 1px 구분선, 밑줄 링크.

---

## 2. 디자인 토큰

```css
:root {
  --ink:        #0A0A0A; /* 본문·제목 */
  --ink-2:      #5C5C5C; /* 보조 텍스트 */
  --ink-3:      #9A9A9A; /* 캡션, 비활성 */
  --line:       #E5E5E5; /* 구분선 */
  --paper:      #FFFFFF; /* 배경 */
  --paper-2:    #F6F6F6; /* 아주 약한 면(입력칸 hover 등) */
  --danger:     #C62828;
  --focus:      #0A0A0A;

  --font-sans:  "Pretendard Variable", Pretendard, "Inter Tight", system-ui, sans-serif;
  --font-mono:  "JetBrains Mono", ui-monospace, monospace; /* 번호·메타 정보 */

  --space-1: 4px;  --space-2: 8px;  --space-3: 16px; --space-4: 24px;
  --space-5: 40px; --space-6: 64px; --space-7: 120px; --space-8: 180px;

  --container:  1200px;
  --gutter:     24px;
  --radius:     0;
  --dur:        180ms;
  --ease:       cubic-bezier(0.2, 0, 0, 1);
}
```

## 3. 타이포그래피

| 역할 | 크기 / 행간 | 굵기 | 비고 |
|---|---|---|---|
| Display | clamp(48px, 7vw, 104px) / 1.0 | 700 | 자간 -0.04em, 히어로 1회만 |
| H1 | 56px / 1.1 | 700 | 자간 -0.03em |
| H2 | 32px / 1.2 | 600 | 섹션 제목 |
| H3 | 20px / 1.4 | 600 | 리스트 항목 제목 |
| Body | 17px / 1.7 | 400 | 최대 폭 62ch |
| Small | 14px / 1.6 | 400 | `--ink-2` |
| Meta | 13px / 1.4 | 500 | `--font-mono`, 대문자·숫자, 자간 0.04em |

- `word-break: keep-all`, 한글 본문 자간 -0.01em.
- 헤드라인은 2~3줄로 의도적으로 끊는다(`<br>` 대신 max-width로).

## 4. 레이아웃

```
┌ header (h72, 하단 1px line) ───────────────────────────────────────┐
│ STUDIO NAME                                 Work  About  Contact ↗ │
└────────────────────────────────────────────────────────────────────┘
  ↕ 120
  Display 헤드라인 (8/12 컬럼)
  보조 문단 (5/12 컬럼, 시작선은 헤드라인과 동일)
  ↕ 120
  ── 1px line ───────────────────────────────────────────────────────
  01   프로젝트 이름                         카테고리        2026  →
  ── 1px line ───────────────────────────────────────────────────────
  02   …
  ↕ 180
┌ footer (상단 1px line) ─────────────────────────────────────────────┐
│ hello@studio.com (대형 링크)                     © 2026 · Instagram │
└────────────────────────────────────────────────────────────────────┘
```

- 컨테이너 1200px, 좌우 패딩 40px(모바일 20px). 12컬럼, gutter 24px.
- 섹션 제목은 왼쪽 3컬럼, 내용은 오른쪽 9컬럼에 두는 **좌측 라벨 레이아웃**을 반복한다.

## 5. 컴포넌트

### 5.1 헤더 / 내비게이션
- 높이 72px, 배경 `--paper`, 하단 1px `--line`. 로고는 텍스트 워드마크(18px/700, 대문자 허용).
- 메뉴는 15px/500, 간격 32px. 현재 페이지는 밑줄(1px, offset 6px).

### 5.2 버튼
- Primary: 배경 `--ink`, 글자 `--paper`, 높이 52px, 좌우 28px, 모서리 0, 15px/600.
- Secondary: 배경 투명, 1px `--ink` 테두리.
- Text link: 밑줄 1px, hover 시 밑줄 두께 2px. 오른쪽 화살표(→)는 hover 시 4px 이동.

### 5.3 리스트 행 (시그니처)
- 상하 1px `--line`, 높이 88px, `grid-template-columns: 80px 1fr 200px 80px 40px`.
- 번호는 `--font-mono` 13px `--ink-3`. hover 시 행 전체 배경 `--paper-2`, 화살표 이동.

### 5.4 카드
- 테두리·그림자 없이 이미지(4:3, grayscale) + 아래 제목 20px + 메타 13px mono.

### 5.5 입력
- 밑줄형 입력: 하단 1px `--ink`만, 높이 52px, 포커스 시 하단 2px. 라벨은 위에 13px mono.

### 5.6 표
- 헤더 행 13px mono `--ink-2`, 행 구분 1px `--line`, 세로선 없음, 숫자 열 오른쪽 정렬.

### 5.7 푸터
- 상단 1px line, 큰 이메일 링크(40px/600) + 오른쪽 작은 메타 링크.

---

## 6. 인터랙션 & 상태
- 모든 전환은 `--dur` `--ease`. 움직임은 opacity·transform만, 4~8px 이내.
- hover: 링크 밑줄 두께 변화, 리스트 행 배경 변화, 이미지 grayscale 해제.
- focus-visible: 2px `--focus` outline, offset 3px. 절대 제거하지 않는다.
- 빈 상태·로딩: 회색 텍스트 한 줄 + mono 메타("LOADING…"), 스피너 금지.

---

## 7. 반응형 · 접근성
- 960px 이하: 좌측 라벨 레이아웃을 세로로 쌓는다. Display는 48px까지 축소.
- 640px 이하: 리스트 행은 번호·제목·화살표만 남기고 메타는 둘째 줄로.
- 대비: 본문은 `--ink`, 보조 텍스트 최소 `--ink-2`(4.5:1 이상). `--ink-3`는 캡션·장식에만.
- 터치 영역 최소 44px. 모든 인터랙티브 요소는 실제 `<a>`/`<button>`.

---

## 8. 체크리스트
- [ ] 흑·백·회색 외의 색이 쓰이지 않았다(오류·포커스 제외).
- [ ] 그림자·라운드·그라디언트가 없다.
- [ ] 섹션 사이 여백이 120px 이상이다.
- [ ] 텍스트 시작선이 그리드에 맞춰 일치한다.
- [ ] 번호 리스트·1px 구분선·밑줄 링크 중 최소 두 가지가 등장한다.
- [ ] 토큰은 `src/app.css`에만 정의되고 컴포넌트는 변수만 참조한다.
