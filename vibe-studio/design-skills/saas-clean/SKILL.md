# SaaS 클린 블루 스킬 (SaaS Clean)

B2B 소프트웨어 랜딩 페이지에서 흔히 보는 **명료하고 신뢰감 있는** 스타일을 재현하기 위한 명세다. 결과물은 SvelteKit 앱이며, 토큰은 `src/app.css`의 `:root`에 정의하고 `src/routes/+layout.svelte`에서 import한다.

---

## 0. 적용 규칙 (먼저 읽을 것)

1. 메시지 → 근거 → 행동 순서로 섹션을 구성한다. 히어로에는 **한 문장 가치 제안 + 보조 문장 + CTA 2개**.
2. 포인트 색은 **블루 하나**(`--brand`). 상태 색(성공·경고·오류)은 상태 표시에만.
3. 면은 흰 카드 + 1px 테두리 + 아주 옅은 그림자. 큰 그라디언트·글로우 금지(히어로 배경의 은은한 블루 틴트 하나만 허용).
4. 숫자·수치는 실제 데이터가 없으면 `[지표]` 플레이스홀더로 둔다. 가짜 고객 로고·수치를 만들지 않는다.
5. 모든 색·간격은 변수로만 참조한다.

---

## 1. 디자인 DNA

- **정돈된 제품 소개서**: 중앙 정렬 히어로, 그 아래 제품 화면 목업, 3열 기능 카드, 요금제 3단.
- **여백과 정렬로 신뢰감**: 8px 그리드, 카드 높이·간격 일정.
- **시그니처 형태**: 알약형 "새 소식" 배지가 붙은 히어로, 아이콘 박스(36px, 연한 블루 면)가 달린 기능 카드, 추천 요금제 강조 테두리.

## 4. 레이아웃

```
┌ header (h68, white, sticky, 하단 1px) ─────────────────────────────┐
│ ◆ 제품명    기능  요금제  고객사례  문서          로그인 [무료로 시작] │
└───────────────────────────────────────────────────────────────────┘
  hero (brand-tint 배경, 가운데 정렬)
    (● 새 기능: … →) 배지
    Hero 헤드라인 2줄 / Lead / [무료로 시작] [데모 신청]
    제품 화면 목업 카드(radius 16, shadow)
  기능 섹션: Eyebrow + H2 + 3열 카드
  요금제: 3단, 가운데 "추천" 강조
  CTA 밴드: brand 배경 흰 글자 한 줄 + 버튼
┌ footer 4열 링크 + 하단 저작권 ─────────────────────────────────────┐
```

- 컨테이너 1160px, 좌우 24px. 섹션 상하 패딩 80px.
- 카드 그리드 `repeat(3, minmax(0,1fr))`, gap 24px.

## 5. 컴포넌트

### 5.1 헤더
- 높이 68px, sticky, 배경 흰색 + 스크롤 시 하단 1px `--line`.
- 메뉴 15px/500 `--ink-2`, hover `--ink`. 오른쪽 텍스트 "로그인" + Primary 버튼(작은 크기).

### 5.2 버튼
- Primary: `--brand` 배경, 흰 글자, 높이 48px(작은 버튼 40px), 좌우 20px, radius 8px, 15px/600.
- Secondary: 흰 배경, 1px `--line`, 글자 `--ink`. hover 시 배경 `--bg-2`.

### 5.3 배지
- 알약형 `--brand-soft` 배경, `--brand` 글자 13px/600, 앞에 6px 점.

### 5.4 기능 카드
- 흰 배경, 1px `--line`, radius 12px, 패딩 24px, `--shadow-sm`.
- 위에 36px 아이콘 박스(`--brand-soft`, radius 8px, 선 아이콘 `--brand`), 제목 H3, 설명 2~3줄.

### 5.5 요금제 카드
- 기능 카드와 동일 + 가격 40px/800, 기능 목록(✓ 아이콘 `--success`).
- 추천 플랜: 2px `--brand` 테두리 + 상단 "추천" 배지 + `--shadow`.

### 5.6 입력
- 높이 44px, 1px `--line`, radius 8px. 포커스: 테두리 `--brand` + 3px `--brand-soft` 링. 오류: 테두리 `--danger` + 아래 13px 메시지.

### 5.7 표
- 헤더 배경 `--bg-2`, 14px/600 `--ink-2`. 행 높이 52px, 구분 1px `--line`. 상태는 작은 배지.

### 5.8 푸터
- 배경 `--bg-2`, 4열 링크(14px), 하단 1px 선 + 저작권 13px `--ink-3`.

---

## 6. 인터랙션 & 상태
- 카드 hover: 테두리 `--brand`의 30% 톤, 그림자 `--shadow`. 이동은 하지 않는다.
- 버튼 pressed: `--brand-hover`, disabled: 40% 불투명.
- 로딩: 스켈레톤(`--bg-2` 블록). 빈 상태: 아이콘 박스 + 한 줄 설명 + Primary 버튼.

---

## 7. 반응형 · 접근성
- 1024px 이하 2열, 640px 이하 1열. Hero 36px. 헤더 메뉴는 햄버거 메뉴(실제 `<button aria-expanded>`).
- 본문 대비 4.5:1 이상(`--ink-2`까지). `--ink-3`는 플레이스홀더·캡션에만.
- 포커스 링 2px `--brand`, offset 2px.

## 8. 체크리스트
- [ ] 히어로에 가치 제안·보조 문장·CTA 2개가 있다.
- [ ] 포인트 색은 블루 하나다.
- [ ] 카드 간격·높이·모서리가 일정하다.
- [ ] 가짜 수치·고객 로고가 없다(플레이스홀더 사용).
- [ ] 토큰은 `src/app.css`에만 정의됐다.
