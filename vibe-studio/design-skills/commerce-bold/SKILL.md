# 커머스 볼드 스킬 (Commerce Bold)

상품을 많이 보여주고 **빠르게 고르고 담게 하는** 쇼핑몰 스타일을 재현하기 위한 명세다. 결과물은 SvelteKit 앱이며, 토큰은 `src/app.css`의 `:root`에 정의하고 `src/routes/+layout.svelte`에서 import한다. 장바구니 상태는 `src/lib/` 스토어(Svelte 5 runes 클래스)로 공유한다.

---

## 0. 적용 규칙 (먼저 읽을 것)

1. 바탕은 흰색, **행동 유도 색은 레드 하나**(`--cta`). 레드는 구매·담기·할인율에만 쓴다.
2. 가격 위계를 지킨다: 할인율(레드 굵게) → 판매가(검정 굵게) → 정가(회색 취소선).
3. 상품 이미지는 1:1 정사각형, 모서리 8px로 통일. 실제 이미지가 없으면 `--surface-2` 면 + `[상품 이미지]`.
4. 정보 밀도가 높으므로 간격은 촘촘하되 일정하게(8px 그리드).
5. 가짜 리뷰 수·판매량을 만들지 않는다. 데이터가 없으면 해당 줄을 숨긴다.
6. 모든 색·간격은 변수로만 참조한다.

---

## 1. 디자인 DNA

- **매장 진열대**: 상단 검색 중심 헤더, 카테고리 바, 큰 기획전 배너, 5열 상품 그리드.
- **분명한 행동 유도**: 레드 "담기" 버튼과 할인율, 떠 있는 장바구니 개수 배지.
- **시그니처 형태**: 둥근 검색창이 가운데 놓인 헤더, 가로 스크롤 카테고리 칩, 상품 카드의 할인율-가격 2단 표기.

---

## 2. 디자인 토큰

```css
:root {
  --bg:         #FFFFFF;
  --surface-2:  #F5F5F7; /* 이미지 자리, 섹션 배경 */
  --ink:        #111318;
  --ink-2:      #5A5F6B;
  --ink-3:      #9A9FAA;
  --line:       #E7E8EC;
  --cta:        #E8222E; /* 구매·담기·할인율 */
  --cta-hover:  #C4141F;
  --cta-soft:   #FFECEE;
  --navy:       #14213D; /* 기획전 배너 배경 */
  --star:       #FFB400;
  --success:    #12A150;

  --font-sans: "Pretendard Variable", Pretendard, system-ui, sans-serif;

  --space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px;
  --space-5: 24px; --space-6: 32px; --space-7: 48px;
  --container: 1240px;
  --radius-sm: 6px; --radius: 8px; --radius-lg: 14px; --radius-pill: 999px;
  --shadow: 0 6px 18px rgba(17, 19, 24, 0.08);
  --dur: 140ms; --ease: cubic-bezier(0.2, 0, 0, 1);
}
```

```

┌ header (h80): 로고 · [ 둥근 검색창 520 ] · 찜 · 장바구니(배지) ─────┤

  기획전 배너 (navy, r14, h300): 헤드라인 + 기간 + [보러가기] + 상품 이미지 자리
  카테고리 원형 아이콘 8개 (가로)
  섹션 "오늘의 특가" + 상품 그리드 5열 (gap 16)

```

- 컨테이너 1240px, 좌우 20px, 섹션 간격 48px.

## 5. 컴포넌트

### 5.1 헤더 · 검색
- 로고 왼쪽, 검색창 가운데(높이 48px, 2px `--cta` 테두리, 알약형, 오른쪽 돋보기 버튼).
- 장바구니 아이콘 위 레드 원형 배지(18px, 흰 숫자 11px/700).

### 5.2 카테고리 바
- 높이 52px, 15px/600. 현재 카테고리는 하단 2px `--ink`. 모바일은 가로 스크롤 칩.

### 5.3 버튼
- 구매/담기: `--cta` 배경, 흰 글자, 높이 48px, radius 8px, 16px/700. hover `--cta-hover`.
- 보조: 흰 배경, 1px `--line`, 글자 `--ink`.
- 카드 위 담기 아이콘 버튼: 36px 원형, 흰 배경 + `--shadow`.

### 5.4 상품 카드 (시그니처)
- 이미지 1:1(radius 8px) → 상품명 2줄 → `할인율 판매가` 한 줄 → 정가 취소선 → 메타(★ 4.8 · 리뷰 [n]) → 배지(무료배송 `--success` 글자).
- hover: 이미지 scale(1.04), 담기 버튼 노출.

### 5.5 기획전 배너
- `--navy` 배경, radius 14px, 왼쪽 텍스트(흰 Banner + 기간 14px 반투명) + Primary 버튼, 오른쪽 이미지 자리.

### 5.6 입력 · 폼 (주문서)
- 높이 48px, 1px `--line`, radius 8px. 포커스 `--ink` 테두리. 필수 표시는 `--cta` 점.

### 5.7 표 (주문 내역)
- 헤더 `--surface-2`, 상품 썸네일 56px + 이름 + 수량 스테퍼(− n +) + 금액 오른쪽 정렬.

### 5.8 푸터
- `--surface-2`, 고객센터 번호 크게(20px/800), 사업자 정보 12px `--ink-3`.

---

## 6. 인터랙션 & 상태
- 담기 클릭 시 장바구니 배지 숫자가 짧게 커졌다 돌아온다(scale 1.2, 140ms).
- 품절: 이미지 위 반투명 검정 + "품절" 흰 글자, 버튼 비활성.
- 로딩: 카드 스켈레톤(이미지·두 줄). 빈 장바구니: 아이콘 + "담은 상품이 없어요" + 보조 버튼.

---

## 7. 반응형 · 접근성
- 1100px 이하 4열, 768px 이하 2열, 헤더 검색은 아래 줄로.
- 할인율·가격은 색만이 아니라 숫자·취소선으로도 구분. 레드 글자는 17px 굵게 이상에서만.
- 수량 스테퍼·아이콘 버튼은 `aria-label` 필수, 터치 영역 44px.

## 8. 체크리스트
- [ ] 레드는 구매·담기·할인율에만 쓰였다.
- [ ] 상품 카드에 할인율-판매가-정가 위계가 지켜졌다.
- [ ] 상품 이미지가 1:1로 통일됐다.
- [ ] 가짜 리뷰 수·판매량이 없다.
- [ ] 토큰은 `src/app.css`에만 정의됐다.
